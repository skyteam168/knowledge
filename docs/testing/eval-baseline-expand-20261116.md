## 推广时可以怎么说（建议口径）

**可以说（有本跑数支撑）**

- 在本公司真实业务资料上的站内评测集（138 题，含中/英/越改写）中：可答题召回 Recall@5 = 100%，引用正确率 100%，忠实度 ≈99.7%。
- 知识库外问题会拒答或明确说「资料无法确定」，本跑 24 题均未编造制度/数字。
- 质量可复跑、可逐题对比（前端「离线评测」）；模型组合与阈值写进运行环境快照。

**不要说（证据不够或易误导）**

- 「任何问题 / 任意企业都 100%」——评测集仍锚定本库文档，含大量同文档改写。
- 「人工核验的准确率」——忠实度/引用正确率是 **LLM 裁判**（与作答同模型族），适合对比与趋势，不等于人审金标。
- 把 mock 冒烟（运行 A）或 CI 合成金标 166 题当成对外「业务准确率」。

**一句话对外**：找得到、不瞎编、不知道就说不知道——三项都有本库实测数字；上线后继续用真实提问滚动扩充评测集。
